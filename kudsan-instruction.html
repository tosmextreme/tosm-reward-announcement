⚡ Kudsan Tools — คู่มือติดตั้ง & ใช้งาน

เครื่องมือคัดกรองกิจกรรมอัตโนมัติบน Google Sheets · TOSM Extreme

เอกสารนี้สำหรับ user ทุกคนที่จะติดตั้งและใช้งานเครื่องมือ ครอบคลุมตั้งแต่การติดตั้ง วิธีใช้งานแต่ละกิจกรรม และ วิธีใส่/เปลี่ยน API Key ของตัวเอง เพื่อไม่ให้ไปใช้ quota ของคนอื่นโดยไม่ตั้งใจ

ต้องเตรียมอะไรบ้าง (ฟรีทั้งหมด ไม่มีค่าใช้จ่าย) ① ไฟล์สคริปต์ 2 ไฟล์: Sudota-Query.gs และ SudotaSidebar.html  ·  ② Groq API Key ฟรี (console.groq.com/keys)  ·  ③ Gemini API Key ฟรี (aistudio.google.com/apikey) — ไม่ต้องใช้บัตรเครดิต

1การติดตั้ง (ทำครั้งเดียว)

  1. เปิดชีต Query แล้วไปที่ Extensions → Apps Script
  2. กด ＋ → Script ตั้งชื่อ Sudota-Query → เปิดไฟล์ Sudota-Query.gs คัดลอกทั้งหมดมาวาง
  3. กด ＋ → HTML ตั้งชื่อให้ตรงว่า SudotaSidebar → ลบข้อความตัวอย่างทิ้ง แล้ววางเนื้อหาจาก SudotaSidebar.html
  4. เปิดไฟล์ New คัดรายชื่อ tab.gs เดิม → แก้เฉพาะฟังก์ชัน onOpen ให้มีบรรทัด if (typeof addSudotaMenu === 'function') addSudotaMenu(ui); (ให้เมนูขึ้นทั้งสองอัน)
  5. กด 💾 บันทึก → ปิด Apps Script → รีเฟรชชีต 1 ครั้ง
  6. จะเห็นเมนู ⚡ Kudsan Tools โผล่บนแถบเมนูของชีต

2ตั้งค่า Config + ใส่ Key ของตัวเอง (สำคัญ)

  1. เมนู ⚡ Kudsan Tools → Set up config tab (one time) → ระบบสร้างแท็บ ⚙️ Sudota Config ให้
  2. วาง Groq API Key ของคุณ (ขึ้นต้น gsk_…) ที่เซลล์ B4
  3. วาง Gemini API Key ของคุณ (ขึ้นต้น AIza…) ที่เซลล์ B8 — เพื่อให้ตรวจรูปเร็ว
ทำไมต้องใช้ Key ของตัวเอง เครื่องมืออ่าน key จากเซลล์ Config ทุกครั้งที่รัน ดังนั้นถ้าคุณใส่ key ของตัวเอง โควตา AI ฟรีจะถูกนับเป็นของคุณเอง ไม่ไปกิน quota ของคนอื่น (และคนอื่นก็ไม่มากิน quota ของคุณ)
เซลล์ค่าหมายเหตุ
B4Groq API Keyใช้อ่านเงื่อนไข + คัดกรองข้อความ (ขึ้นต้น gsk_)
B5Groq Modelค่าเริ่มต้นใช้ได้เลย ไม่ต้องแก้
B6ปิดบังชื่อ (TRUE/FALSE)TRUE = ปิดบังชื่อบนหน้าประกาศ
B7Groq Vision Modelค่าเริ่มต้นใช้ได้เลย
B8Gemini API Keyใช้ตรวจรูปแบบเร็ว (ขึ้นต้น AIza) — แนะนำอย่างยิ่ง

3วิธีใช้งาน (ทุกครั้งที่มีกิจกรรม)

  1. ให้ส่วนขยาย Sudota ดึงคอมเมนต์ของกิจกรรมลงในแท็บดิบก่อน → คลิกไปที่แท็บนั้น
  2. เมนู ⚡ Kudsan Tools → Open Kudsan panel (แผงเปิดด้านขวา ตรวจว่าชื่อแท็บด้านบนถูกต้อง)
  3. ขั้นที่ 1 — อ่านเงื่อนไข: วางข้อความโพสต์กิจกรรม → กด Read condition (AI) → ตรวจ/แก้สิ่งที่ AI อ่านได้
  4. ขั้นที่ 2 — คัดกรอง: กด Screen the raw tab → ดูจำนวน และ วงล้อ % ใช้ได้ ว่าน่าเชื่อถือไหม
    • ถ้ากิจกรรมต้องแนบรูป: เลือก AI engine = Gemini แล้วกด Verify all images (ระบบบอกเวลาโดยประมาณ ~9 วิ/รูป)
    • ระหว่างรันสามารถ Stop/รันต่อ และ Retry รายการที่ติด rate-limit ได้ ความคืบหน้าไม่หาย
  5. ขั้นที่ 3 — สร้างสเปรดชีต: พิมพ์ชื่อกิจกรรม → เลือกสร้างแบบ ทั้งหมด / เฉพาะสุ่ม / เฉพาะเข้าร่วม (ไม่รวมคนที่ถูกตัดสิทธิ์)
  6. ขั้นที่ 4 — ประกาศขึ้นหน้าเว็บ: ใส่ event id ให้ตรงกับใน reward-admin → Publish to LIVE (hidden) (ขึ้นแบบซ่อนก่อน) → เมื่อถึงเวลาจริงค่อยกด Reveal
ก่อน Export หรือ Publish ทุกครั้ง ให้ดู วงล้อ % ใช้ได้ ก่อน — ถ้ามี "ไม่แน่ใจ" เยอะ (สีเหลือง) ให้กดดูรายการ Unsure แล้วตรวจด้วยตาก่อน จะได้ไม่ประกาศผิด

4ความปลอดภัยของ Key + วิธีเปลี่ยน (กัน usage)

key ทั้งหมดเก็บอยู่ในแท็บ ⚙️ Sudota Config (B4 = Groq, B8 = Gemini) ซึ่ง ทุกคนที่ "แก้ไข" ชีตนี้ได้ จะเห็น key และใช้ quota ได้ ดังนั้นถ้าอยากกันไม่ให้คนอื่นมาใช้ quota ของคุณ ให้ทำตามนี้:

วิธีที่แนะนำที่สุด — ต่างคนต่าง Key

  • ให้แต่ละทีม/แต่ละคน ทำสำเนาชีตของตัวเอง (File → Make a copy — สคริปต์จะติดไปด้วย) แล้วใส่ key ฟรีของตัวเอง ที่ B4/B8
  • key ทั้ง Groq และ Gemini เป็นของฟรี สมัคร 2 นาที ไม่ต้องใช้บัตร → ทุกคนมี quota ของตัวเอง ไม่ต้องแย่งกัน
  • อย่าใส่ key ส่วนตัวของคุณ ลงในชีตที่มีคนแก้ไขได้หลายคน

ถ้าจำเป็นต้องใช้ชีตเดียวร่วมกัน

  • จำกัดสิทธิ์เป็น "ดูอย่างเดียว (Viewer)" สำหรับคนที่ไม่ต้องรันเครื่องมือ — คน Viewer จะเห็น/ใช้ key ไม่ได้
  • ให้สิทธิ์ Editor เฉพาะคนที่ไว้ใจและต้องรันจริงเท่านั้น

วิธีเปลี่ยน / เพิกถอน Key

  1. เปลี่ยน key: แก้ค่าที่เซลล์ B4 (Groq) หรือ B8 (Gemini) ได้เลย — เครื่องมืออ่านค่าใหม่ทุกครั้งที่รัน ไม่ต้องตั้งค่าอะไรเพิ่ม
  2. ถ้าสงสัยว่า key รั่ว/ถูกใช้โดยไม่ได้รับอนุญาต: ไปที่หน้าเว็บของผู้ให้บริการแล้ว ลบ/เพิกถอน (revoke) key เดิมทิ้ง แล้วสร้างใหม่
    • Groq: console.groq.com/keys
    • Gemini: aistudio.google.com/apikey
    พอ revoke แล้ว key เดิมจะใช้ไม่ได้ทันที ต่อให้ใครก๊อปไปก็ใช้ไม่ได้ — จากนั้นวาง key ใหม่ที่ B4/B8
ห้ามทำ อย่าโพสต์ key ลงในแชตสาธารณะ, สกรีนช็อตที่เห็น key, หรือส่งไฟล์ที่มี key ให้คนนอกทีม — ถ้าเผลอหลุด ให้ revoke แล้วออกใหม่ทันที (ฟรี)

5Supabase Key (สำหรับหน้าประกาศรางวัล — ขั้นสูง)

ค่า Supabase ฝังอยู่ในโค้ด Sudota-Query.gs (บล็อก SUDOTA.supabase): มี url, key (publishable), และ writeToken ซึ่งเป็นรหัสที่อนุญาตให้ "เขียน" ขึ้นหน้าประกาศรางวัล

ต่างจาก AI Key ตรงไหน ค่า Supabase ชุดนี้เป็น ค่าสาธารณะ ชุดเดียวกับที่อยู่ในหน้า reward-admin.html อยู่แล้ว — ไม่ได้คิดค่าใช้จ่ายตาม usage แบบ AI key จึงไม่ใช่ความเสี่ยงเรื่อง "โดนใช้ quota" โดยตรง แต่เป็นเรื่องสิทธิ์เขียนหน้าประกาศ

ถ้าต้องการ เปลี่ยน writeToken เพื่อไม่ให้คนเดิมเขียนหน้าประกาศได้อีก ต้องแก้ให้ตรงกัน 2 ที่:

  1. ฝั่ง Supabase (นโยบาย/ฟังก์ชันที่ตรวจ token)
  2. ค่า writeToken ในโค้ดทั้ง Sudota-Query.gs และ reward-admin.html ให้เป็นค่าใหม่เหมือนกัน
แนะนำ ขั้นตอนนี้กระทบทั้งเครื่องมือและหน้าประกาศพร้อมกัน ถ้าจะเปลี่ยนจริง ให้ทำร่วมกับผู้ดูแลระบบ (หรือทักผมมาช่วยทำ) และ ห้ามนำ Supabase service_role key ใส่ลงในโค้ดเด็ดขาด

6ปัญหาที่พบบ่อย

อาการวิธีแก้
ขึ้น rate-limit (429) ตอนตรวจรูปปกติของ tier ฟรี — เครื่องมือจะหน่วงและลองใหม่ให้เอง ที่เหลือกดปุ่ม 🔁 Retry / หรือสลับไปใช้ Gemini ซึ่งโควตาสูงกว่า
ขึ้น gemini error 404เครื่องมือจะหา model ที่ใช้ได้ให้อัตโนมัติ ถ้ายังขึ้น key rejected (400/403) = key ผิด → ใส่ key Gemini ใหม่ที่ B8
ตรวจรูป ช้าปกติ ~9 วิ/รูป เพราะต้องโหลดรูปจาก Facebook ทีละรูป — ปล่อยรันทิ้งไว้ได้ ความคืบหน้าถูกบันทึก กด Stop/รันต่อได้
ไม่เห็นเมนู ⚡ Kudsan Toolsตรวจว่าวางไฟล์ครบ + แก้ onOpen แล้ว → บันทึก → รีเฟรชชีต 1 ครั้ง
วงล้อขึ้น ไม่แน่ใจเยอะ (สีเหลือง)กดดูรายการ Unsure แล้วตรวจด้วยตาก่อน export/publish
